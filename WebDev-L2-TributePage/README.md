# Tribute Page — Web Development & Designing (Level 2, Task 2)

## Objective
A visually engaging tribute page dedicated to Dr. A.P.J. Abdul Kalam, India's "Missile Man" and 11th President. Built using HTML and CSS, with a focus on layout, typography, and visual hierarchy.

## Tech Stack
- HTML5
- CSS3 (Flexbox, custom animations, responsive design)

## Features
- Full-height hero section with background image and overlay
- Page title with subject's name and tagline
- Prominent circular profile image with hover effect
- Biography section with 3 original paragraphs
- Key Achievements timeline with connected line and styled markers
- Distinctly styled quote block with attribution
- Two background color themes (dark blue sections + light sections)
- Two font styles — Georgia (serif) for headings/quotes, Segoe UI (sans-serif) for body text
- Hover animations on timeline items, image, and headings
- Fully responsive layout across screen sizes

## How to Run
1. Clone this repository
2. Navigate to the `WebDev-L2-TributePage` folder
3. Open `index.html` in any browser
