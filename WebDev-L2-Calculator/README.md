# Calculator — Web Development & Designing (Level 2, Task 1)

## Objective
A fully functional browser-based calculator built using HTML, CSS, and vanilla JavaScript. Supports basic arithmetic operations with a clean, button-based interface.

## Tech Stack
- HTML5
- CSS3 (Grid layout)
- JavaScript (Vanilla, no libraries)

## Features
- Numeric buttons (0–9) and decimal point
- Operator buttons: addition, subtraction, multiplication, division
- Equals button to evaluate expressions
- Clear (C) and Backspace buttons
- Operator chaining (e.g. 5 + 3 × 2) without needing a reset
- Division-by-zero handled gracefully with an error message
- Prevents invalid input: double decimals, consecutive operators, starting with an operator
- Built with CSS Grid for button layout
- All interactivity handled via addEventListener — no inline onclick attributes
- No use of eval() — expression evaluation handled manually with operator precedence

## How to Run
1. Clone this repository
2. Navigate to the `WebDev-L2-Calculator` folder
3. Open `index.html` in any browser
