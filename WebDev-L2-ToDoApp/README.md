# To-Do Web App — Web Development & Designing (Level 2, Task 3)

## Objective
An interactive to-do list application that allows users to add, edit, complete, and delete tasks, organized into Pending and Completed lists. Built with HTML, CSS, and vanilla JavaScript.

## Tech Stack
- HTML5
- CSS3 (Grid layout, gradients, animations, responsive design)
- JavaScript (Vanilla, DOM manipulation, localStorage)

## Features
- Input field + Add Task button to create new tasks
- New tasks appear immediately in the Pending list
- Mark Complete toggle — moves tasks between Pending and Completed lists
- Edit button — allows inline modification of task text
- Delete button — permanently removes a task (with confirmation prompt)
- Live task count indicators for both Pending and Completed lists
- Progress bar showing overall completion percentage
- Timestamps on each task (Added date/time, Completed date/time)
- Tasks persist across page refreshes using localStorage
- Empty state messaging when a list has no items
- Smooth animations on task add/hover
- Fully responsive layout — stacks to a single column on smaller screens

## How to Run
1. Clone this repository
2. Navigate to the `WebDev-L2-ToDoApp` folder
3. Open `index.html` in any browser
